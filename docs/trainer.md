# Trainer

`codemmet train` is an interactive trainer for the abbreviation syntax. It
teaches the composition operators first, then the per-language trigger
vocabulary, and it grades you against the **real** engine — every exercise is
generated by expanding actual abbreviations, so what you practice is exactly
what you get when you type.

```console
$ codemmet train
```

With no arguments it starts a guided lesson for Rust in a full-screen terminal
UI. Press `Esc` to quit at any time.

Inside Neovim, the shipped plugin's
[`:CodemmetTrain` command](editors.md#keymaps-and-commands) opens the trainer
in a terminal split, training the current buffer's language.

## Two directions

Exercises come in both directions, mixed:

- **Reverse** — you are shown target code and write an abbreviation that
  produces it. Any abbreviation that expands to the target is accepted, not
  just one "official" answer: `fori10>pr` and `fori:i,10>pr` both pass. As you
  type, a live preview shows what your abbreviation currently expands to.
- **Forward** — you are shown an abbreviation and predict its expansion.
  Short one-liners are free-typed; multi-line expansions are multiple choice,
  with plausible near-miss distractors.

## Modes

Choose a mode with `--mode`:

| Mode | What it does |
| --- | --- |
| `lessons` (default) | A guided progression: a short concept intro per level, then a curated set of exercises, advancing level by level. |
| `drills` | Endless randomized exercises. Use `--level` to focus one level, or omit it to mix all levels. |
| `review` | Replays only the spaced-repetition items that are due (see below). |
| `sandbox` | Free play — type any abbreviation and see it expand, with a scrollback and live preview. No scoring. |

```console
$ codemmet train --mode drills --level 3      # nesting drills, endless
$ codemmet train --mode review                # what's due today
$ codemmet train --mode sandbox               # a scratch expander
$ codemmet train --lang python                # train another language
```

### Levels

Lessons and focused drills are organized into nine levels, taught in order:

1. **Single triggers** — `pr`, `ret`
2. **Arguments** — `fn:main`, `fori:i,10`
3. **Nesting** `>` — `fn:main>pr`
4. **Siblings** `+` — `if+el`
5. **Repeat** `*` — `arm*3`
6. **Climb-up** `^` — `fn:main>pr^ret`
7. **Grouping** `( )` — `(fn:main>pr)+ret`
8. **Composites** — `dstruct:Point`, `classp:Point` (aliases that expand to a
   whole scaffold — see [composite snippets](snippets.md#composite-snippets))
9. **Data-driven** `*[…]` — `struct:P>field*[x:i32,y:f64]`,
   `mod*[parser,lexer]>mtest*[empty,unicode]` (an inline collection repeats a
   node once per item — see [data-driven expansion](context-codegen.md))

Pass `--level N` (1–9) to focus a single level; otherwise lessons cover all
nine in sequence and drills mix them.

## Keys

In the full-screen UI:

| Key | Action |
| --- | --- |
| type / `Backspace` | edit your answer |
| `Enter` | submit an answer, begin a lesson, or continue past feedback |
| `Tab` | reveal the next hint (trigger names, then operators) |
| `Ctrl+R` | reveal the answer |
| `Ctrl+K` | skip the current exercise |
| `Esc` | quit |

Hints are progressive: the first press names the triggers involved, the next
names the operators. After three wrong attempts the answer is revealed
automatically.

### Line mode

When output is piped or not a terminal, the trainer automatically falls back to
a line-based interface; force it with `--plain`. There you type your answer and
press Enter, or use the commands `:hint`, `:show`, `:skip`, and `:quit`.

## Spaced repetition

Every trigger and operator you practice becomes a review item scheduled with
[Leitner boxes](https://en.wikipedia.org/wiki/Leitner_system): answer it
cleanly and it moves to a longer interval (1, 3, 7, 14, then 30 days); miss it
or reveal the answer and it drops back to daily review. `--mode review` shows
exactly the items that are due, and the end-of-session summary tells you how
many are waiting:

```
session: 6 solved of 8 shown · 75% of answers correct · best streak 4 · 5 due for review (run `--mode review`)
```

## Progress

Progress persists across sessions — lifetime stats, completed lessons, and the
review schedule — as JSON under your data directory
(`~/.local/share/codemmet/trainer.json` on Linux,
`~/Library/Application Support/codemmet/trainer.json` on macOS).

- `--data-file <path>` uses a different file (handy for a throwaway practice
  run, or per-project progress).
- `--reset` deletes the saved progress and exits.

```console
$ codemmet train --reset
progress reset (/home/you/.local/share/codemmet/trainer.json)
```

## Languages

Guided lessons ship a hand-authored progression for every built-in language —
Rust, Python, C, C++, JavaScript, TypeScript, and Go — each taught in the same
level order but using that language's own triggers and idioms. Pick one with
`--lang` (a language id or a file extension like `py` or `ts`):

```console
$ codemmet train --lang go
$ codemmet train --lang ts --mode drills
```

Drills, review, and sandbox work for any configured language, using exercises
generated from its snippet pack. Whichever triggers are configured — built-ins
plus your own [custom snippets](snippets.md) and project-local packs — are fair
game, so the trainer also teaches the vocabulary you have added yourself.

## Reproducible sessions

`--seed <N>` makes exercise generation deterministic — the same seed produces
the same sequence. Useful for sharing a specific practice set or for filing a
bug report.

## Tips

- Start with `lessons` to learn the operators in order, then switch to `drills`
  to build speed and `review` to retain it.
- In a reverse exercise, lean on the live preview: type a guess and watch it
  expand toward the target.
- Stuck? `Tab` for a nudge before you reveal — a hint keeps the item lower in
  the review schedule than a full reveal does.
